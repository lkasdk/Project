# Грубо говоря электронный дневник

Привет! Это мой проект "Электронный дневник", который я сделал для сдачи работы. 
По сути, это простая программа на WPF, чтобы смотреть оценки, искать учеников и предметы.

## Что тут есть?
В проге можно:
- **Смотреть список оценок** (все подтягивается из базы).
- **Искать по имени ученика** (просто вводишь имя, и список фильтруется).
- **Искать по предмету** (то же самое, но для предметов).
- **Сортировать список** (кнопки А-Я и Я-А, чтобы было удобно искать).

## Как запустить?
1. Скачай проект.
2. Открой файл `.slnx` или `.csproj` в Visual Studio.
3. Нажми "Пуск" (или F5).
4. Всё должно заработать! (Ну, если база данных на месте).

## На чем написано?
- **C#**
- **WPF** (для интерфейса)
- **Entity Framework** (чтобы работать с базой данных)
